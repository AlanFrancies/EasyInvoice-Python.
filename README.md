
# EasyInvoice Python

A beginner-friendly Python invoice generator that creates printable invoices.

## Features

- Enter business and customer details
- Add products or services with quantities and prices
- Calculate invoice totals automatically
- Generate an HTML invoice
- Print or save the invoice as a PDF

## Requirements

- Python 3
- A web browser

No third-party Python packages are required.

## How to Run

1. Download `easyinvoice.py` from this repository.
2. Open Python IDLE or a terminal.
3. Run the program:

   python easyinvoice.py

4. Enter the business, customer, and invoice details.
5. Open the generated invoice in your browser.
6. Select Print / Save as PDF to save a copy.
